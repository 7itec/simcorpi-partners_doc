🚗 GET /vehicles/partners/integration/bi

Retorna a frota de veículos ativos, com todos os campos disponíveis para consumo do BI.

1. Endpoint

GET /vehicles/partners/integration/bi
Propriedade Valor
Autenticação Header x-api-key obrigatório
Paginação Cursor por _id
Cache Sem cache — sempre lê do banco
Filtro fixo Somente veículos com status === ACTIVE
Ordenação _id ascendente

2. Query Parameters

Parâmetro Tipo Obrigatório Regra
limit number Sim Inteiro entre 1 e 300
cursor string Não Deve ser um ObjectId válido (24 hex chars)

3. Paginação por Cursor

Este é um modelo diferente das outras rotas:

  1. Primeira chamada: envie apenas limit, sem cursor.
  2. Chamadas seguintes: envie cursor = _id do último item retornado.
  3. Condição de parada: quando a quantidade retornada for menor que limit, você chegou ao fim.

Diferença importante: diferente das rotas de CSAT e Pontualidade, aqui a resposta é um array direto — não há envelope com data, count ou isLastPage. A condição de parada é o tamanho do array retornado.

4. Shape da Resposta

Array de objetos com os seguintes campos:

Campo Tipo Descrição
_id string Identificador único do veículo — use para paginação
plate string | null Placa do veículo
model string | null Modelo do veículo
status string Sempre ACTIVE
process string | null Processo no qual o veículo está alocado
management string | null Gerência responsável
servicePackage string | null Pacote de serviço contratado
requestOrigin string | null Origem da solicitação
serviceTypes string | null Tipo de serviço (ex.: DEDICADO)
serviceDescription boolean | null Indicador de descrição de serviço
modal string | null Modal de transporte (ex.: MICRO-ONIBUS)
direction string | null Diretoria responsável
executiveManagement string | null Gerência executiva
city string | null Cidade de operação
state string | null Estado de operação
contractNumber number | null Número do contrato
equipmentCode number | null Código do equipamento (uso interno)
dangerousness boolean | null Indicador de periculosidade
monthlyWorkRegime string | null Regime mensal de trabalho
dailyWorkRegime number | null Carga horária diária
quantityOfKilometersDriven number | null KM rodados
numberOfPassengers number | null Capacidade de passageiros
planningGroup number | null Grupo de planejamento
planningCenter number | null Centro de planejamento
observations string | null Observações livres

5. Exemplos

5.1 Primeira página (sem cursor)

curl -G "https://<host>/vehicles/partners/integration/bi" \
  --data-urlencode "limit=300" \
  -H "x-api-key: $X_API_KEY"

6. Erros Comuns

HTTP Cenário Mensagem
400 cursor não é um ObjectId válido Cursor deve ser um ObjectId válido!
400 limit fora da faixa (1–300) Mensagem do validador
401 API key inválida ou ausente Chave inválida
401 API key expirada Chave expirada
500 Falha interna Mensagem variável

Atenção ao cursor: na primeira chamada, omita o parâmetro em vez de enviar string vazia. O cursor deve ser exatamente o _id do último item retornado — 24 caracteres hexadecimais.
